## Agentic Workflows
---
Obsidian supports terminal and CLI tools like Opencode, Claude Code, Codex, Hermes Agent, ... etc., this vault is structured to give instructions to the agents/tool that you deploy in order to help with your studies/projects. these include the followings:

- **Moodle Integration**: the vault has instruction on integrating Moodle with the Agents and provides a way to automatically get data from your University/Institution.
- **Performance Evaluation**: the vault supports grading and correcting user inputs/notes in order to enhance ability in desired domains/fields of study.
- **Flashcards Creation**: Flashcards are an integral part of this vault and their creation is streamlined through python scripts and agent skills that make the whole process easier, faster, and less prone to errors (hopefully).
- **Other Integrations**: mcps of services like gmail, Github, Google Calendar, Google sheets, Outlook,..etc. are supported to be integrated into the vault through Composio.

## Requirements
---
1. Install Opencode and link it to your provider: https://opencode.ai/product
2. Get the Moodle repo for downloading and notifying you: https://github.com/C0D3D3V/Moodle-DL
3. Connect your Composio MCP account to your Opencode: https://composio.dev/
4. **Optional for OCR**: Connect your Openrouter api key: https://openrouter.ai/

### Notes on requirements

Opencode is the harness that we will be using in this vault, please do not hesitate to use any other harness (for example claude code, hermes agent, pi, ...etc) since MCPs should work on the majority of them. Furthermore, working with Moodle shouldn't be hard since the repo works on the standard moodle API and the agent can configure that for you if you face any difficulties.

Speaking of agents, using a harness + Openrouter is in my opinion the best combo ( opencodeGO for lightweight use is good as well ). Opencode provides the ability to define and work with agents/skills and the vault should have some of the basic agents that you might need during your studies.

On the subject of OCRing your lecture notes/handwritten notes: the best and cheapest models I have found are Gemini-flash and GPT-Luna, at their latest versions.
